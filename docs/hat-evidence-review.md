# Independent HAT evidence review

The Coela adapter selects its admitted source and the native semantic receipt. It
passes only references and observed test evidence to Software Architect v2; the
HAT owns stage-specific evidence consistency. There is no copied domain rule,
meaning compiler, runtime grant or second worker in Engineering.

Acceptance first runs the actual pinned sem-lang consumer (explicit temporary
adoption, native compilation and durable reload). Its exact module/term/definition
revision becomes the selected review binding. The HAT receives a verified native
test observation whose digest identifies the real receipt. The independent caller
asserts a supported **test** claim but missing **publication/deployment** evidence.
Meaning still has factual `needs-evidence`; neither receipt authorizes an action.
A changed selection fails instead of implicitly adopting another native revision.

Lifecycle definition 1.3.0 declares the projected finding scalars, evidence-array
JSON SHA256, exact owner sources and HAT consumer fingerprints. The actual full
output is independently compared before projection. All existing Plugin, Web,
semantic and MCP interfaces remain checked. This does not validate unobserved
callers, semantic equivalence, factual truth or Hatter authority.

The candidate CI builds pinned public HAT source on an ephemeral hosted runner.
This is source acceptance only. Keep this caller PR as draft until HAT 0.11.0 is
published, anonymously verified, then accepted from its exact immutable bundle.
Do not run the active Hatter path or resume held host/isolation tests. A public
owner build/attestation does not replace a signed installation catalog.
